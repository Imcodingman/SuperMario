# 超级玛丽 H5

用原生 HTML5 Canvas + JavaScript 写的横版闯关小游戏。没有依赖，也不用构建，手机和电脑浏览器都能玩。

## 在线试玩

https://imcodingman.github.io/SuperMario/ （手机浏览器直接打开即可）

## 运行

直接用浏览器打开 `index.html`，或者起一个静态服务器：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

部署时把 `index.html` 和 `game.js` 放到任意静态托管上即可（GitHub Pages、OSS、Nginx 等都行）。

## 操作

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | ← → / A D | 左下方向键（可滑动切换方向） |
| 跳跃（按住跳得更高） | Z / 空格 / ↑ / W | A 键 |
| 加速跑 | 朝同一方向一直走，约 1 秒后自动加速 | 同左 |
| 暂停 | P / Esc | ❚❚ 按钮 |
| 静音 | M | ♪ 按钮 |

## 玩法内容

- 一整关 1-1 风格关卡：水管、砖块、问号砖、台阶、坑洞、终点旗杆和城堡
- 顶问号砖出金币或蘑菇；吃蘑菇变大，变大后能顶碎砖块
- 踩栗子怪，连续踩分数翻倍；从下方顶砖块也能把上面的敌人顶飞
- 倒计时、生命数、中途存档点、每 100 金币奖励一条命
- 抓旗杆的高度越高分数越多，剩余时间会换算成分数
- 最高分存在本地（localStorage）
- 所有美术都是代码画的像素图，音效和背景音乐用 WebAudio 实时合成，没有外部素材
- 手机横屏会自动加宽视野，竖屏也能玩；切到后台时自动暂停
